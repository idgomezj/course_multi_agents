# Monthly Planning — Case 0

1. Retrieve company policy.
2. Inspect inventory and open purchase orders.
3. Forecast each finished product with the trained demand model.
4. Convert planned production into BOM requirements.
5. Check material timing before placing new purchase orders.
6. Compare authorized suppliers using lead time, delay risk, MOQ, and total cost.
7. Schedule production only on compatible lines and within capacity.
8. Compare feasible alternatives using total operational cost.
9. Validate the candidate plan before finalizing it.
