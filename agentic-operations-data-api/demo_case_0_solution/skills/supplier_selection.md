# Supplier Selection — Case 0

1. Check existing purchase orders first.
2. Determine required quantity and latest acceptable arrival.
3. Retrieve supplier evidence from RAG.
4. Get all authorized supplier options.
5. Respect MOQ.
6. Use the trained supplier-delay model when timing matters.
7. Compare unit price, timing risk, and downstream operational cost.
8. Choose the feasible alternative with the lower total expected cost.
