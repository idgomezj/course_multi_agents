# Case 0 — Complete Worked Example

Case 0 is the only fully worked example. It exists so students can see the expected level of analysis before beginning Teams 1–5.

The example demonstrates:
- training the assigned PyTorch demand and supplier-risk models;
- configuring retrieval for the Case 0 company documents;
- designing planning, sourcing and cost-comparison procedures;
- producing a four-week production and purchasing plan;
- validating feasibility and comparing total operating cost.

For scenario T0-P01, the worked plan targets full service without overtime. The production quantities are 950 FG01, 762.5 FG02 and 570 FG03 in each of the four weeks. Existing RM03 and RM05 purchase orders are used before new purchases are added.

The additional material purchases are staggered across the month to reduce carrying cost:
- RM01: 2,500 units from SUP01 ordered on day 7 and another 2,500 on day 14;
- RM02: 1,200 units from SUP01 ordered on day 15;
- RM05: 2,500 units from SUP03 ordered on day 19;
- RM06: 2,000 units from SUP03 ordered on day 12 and another 2,000 on day 19.

The reference monthly cost for this public scenario is 73,999.05 and the reference service level is 100 percent.

This is a teaching example, not a reusable answer. Teams 1–5 have different model tasks, data distributions, constraints and cost structures.
