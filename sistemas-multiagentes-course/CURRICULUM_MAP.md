## Cobertura moderna adicional

Sin sustituir el contenido oficial, se añaden ejemplos contemporáneos:

- LLM como mecanismo cognitivo de un agente
- Pydantic para mensajes y estado tipados
- tool calling
- memoria local
- recuperación local
- supervisor y critic
- ejecución paralela
- validación estructurada
- integración opcional con API LLM

Estos elementos se presentan como evolución tecnológica de la implementación, no como reemplazo de los conceptos de SMA.
