# Curriculum Alignment

It combines classical Multi-Agent Systems (MAS) foundations with current LLM-agent engineering.

## Modern Additions

The course also includes topics that are central to current LLM-agent engineering:

- structured outputs,
- semantic embeddings,
- semantic RAG,
- persistent memory,
- toolsets and capabilities,
- MCP,
- approval/deferred tools,
- prompt-injection boundaries,
- Pydantic Graph,
- usage budgets,
- hooks,
- code-first evals,
- trajectory evaluation,
- sub-agents,
- heterogeneous models,
- A2A,
- deep-agent concepts,
- durable execution concepts.

## Teaching Principle

Classical concepts define **what problem the system is solving**.

Modern frameworks define **how we implement the system today**.

The course intentionally keeps those two levels separate.
