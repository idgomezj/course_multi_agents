How token costs work here

All three examples use locally executed algorithms/models. There is no billable per-token provider charge, even for the pretrained model. Its tokenizer produces NLI input tokens; those are workload measurements, not AWS invoices. Per-message infrastructure cost depends on EC2 hours, memory fit, storage and egress. On Bedrock or an external paid model API, you must select that provider's specific model and pricing separately.

  • Approximate service request/response payload sizes are included in JSON; network transfer assumes JSON bodies and excludes HTTP/TLS headers.
  • Internet inbound is generally free; outbound price assumes 100 GB free and USD 0.09 / GB above that; these are editable assumptions.
  • EC2 rates: m7i.large $0.1008/h, c7i.xlarge $0.1785/h, g5.xlarge $1.006/h. gp3: USD 0.08/GB-month.

Limitations & reproducibility

The stress test is an in-process, bounded-arrival experiment, NOT an HTTP server load test. Shared pipeline calls under threads may not scale like multiple independent workers. Repeating 20 classroom messages is not an independent accuracy benchmark. All AWS totals are scenarios until measured on the specific EC2 hardware under real networking.
